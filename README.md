# CamXperience : VR DSLR Simulator
VR 체화 인터랙션 설계 연구 : CamXperience  
Presented by Team Esim
Made by 심우호, 이진명, 이정은  
  
### 사용스택  
Unity3D 2022  
Blender  
MetaQuest3 
  
  
### 개요  
복잡한 조작 매커니즘을 가진 실제 장비를 가상현실에서 체화된 인터랙션을 통해 장비 조작 훈련을 진행하는 시뮬레이터
상용 VR Device만으로 다중 감각 피드백을 정교하게 설계하여 실제 장비를 다루는 것처럼 UX 제공을 목표로 한다.
